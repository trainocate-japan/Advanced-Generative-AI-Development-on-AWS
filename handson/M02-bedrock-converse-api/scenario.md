# モジュール 2: 高度なデータ処理と品質保証 - ハンズオンシナリオ

## シナリオ概要

あなたはヘルスケア企業のデータエンジニアです。患者からのフィードバック（テキスト、画像、音声）を統合的に処理し、品質を保証しながら基盤モデルに入力するデータパイプラインを構築する任務を担当しています。

要件：
- テキスト入力のデータ検証と PII 自動検出・マスキング
- 画像（診断書スキャン）のマルチモーダル処理
- バッチ処理による大量データの効率的な処理
- スライディングウィンドウによる会話コンテキスト最適化

## 学習目標

このハンズオンを完了すると、以下ができるようになります：

1. **データ検証**: 基盤モデル入力の品質検証ワークフローを設計・実装する
2. **マルチモーダル処理**: テキスト + 画像を統合した Converse API 呼び出しを実装する
3. **入力最適化**: トークン効率を最大化するプロンプト圧縮とコンテキスト管理を実装する
4. **バッチ処理**: SQS + Lambda による動的バッチサイジングを実装する

## アーキテクチャ

```
┌──────────────┐     ┌──────────────┐     ┌───────────────┐
│  Data Source │────▶│  Validation  │────▶│  Processing   │

                     ┌──────▼───────┐       ┌──────▼───────┐
                     │ PII Detection│       │  Bedrock     │
                     │ (Comprehend) │       │ Converse API │
                     └──────────────┘       └──────────────┘
```

## 使用する AWS サービス

- Amazon Bedrock（Converse API - テキスト・画像）
- Amazon Comprehend（PII 検出）
- AWS Lambda（検証・処理）
- Amazon SQS（バッチキュー）
- Amazon S3（入力データ）
- Amazon DynamoDB（処理結果）
