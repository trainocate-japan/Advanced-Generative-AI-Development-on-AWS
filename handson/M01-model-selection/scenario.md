# モジュール 1: 基盤モデルの選択と設定 - ハンズオンシナリオ

## シナリオ概要

あなたは金融サービス企業のAIアーキテクトです。社内のドキュメント処理システムに生成AIを導入するプロジェクトを任されました。以下の要件を満たすシステムを設計・実装する必要があります：

- 複数の基盤モデル（Claude、Nova、Llama）を用途に応じて使い分ける
- プロバイダー障害時にもサービスを継続できるレジリエントなアーキテクチャ
- コストを最適化しながらパフォーマンス要件を満たす動的ルーティング

## 学習目標

このハンズオンを完了すると、以下ができるようになります：

1. **モデル評価**: 複数プロバイダーの基盤モデルを比較評価し、ユースケースに最適なモデルを選定する
2. **動的ルーティング**: API Gateway + Lambda による動的モデル選択アーキテクチャを構築する
3. **レジリエンス**: サーキットブレーカーパターンとフォールバック機構を実装する
4. **コスト管理**: コストベースの自動モデル切り替えロジックを実装する
