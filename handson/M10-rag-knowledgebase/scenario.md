# モジュール 10: エンタープライズ統合パターン - ハンズオンシナリオ

## シナリオ概要

あなたはグローバル製造企業のクラウドアーキテクトです。既存のオンプレミス ERP システム、CRM、社内 Wiki を AI サービスと統合するエンタープライズアーキテクチャを設計・実装します。セキュリティ、マルチ環境デプロイ、ハイブリッドクラウド対応が必要です。

## 学習目標

1. **API 統合**: RESTful API とイベント駆動アーキテクチャで AI サービスを既存システムに接続する
2. **セキュアアクセス**: IAM、VPC エンドポイント、フェデレーションによるアクセス制御
3. **マルチ環境**: 開発→ステージング→本番の CI/CD パイプライン設計
4. **ハイブリッド**: オンプレミスとクラウドをまたぐ AI ワークロードの配置

## 使用する AWS サービス

- Amazon API Gateway（REST/WebSocket API）
- AWS PrivateLink / VPC エンドポイント
- AWS IAM（フェデレーション、ロールベースアクセス）
- Amazon EventBridge（イベント駆動統合）
- AWS CodePipeline（CI/CD）

## 所要時間

約 60 分
