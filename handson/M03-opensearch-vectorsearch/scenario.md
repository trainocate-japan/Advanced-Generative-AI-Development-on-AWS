# モジュール 3 補足: Amazon OpenSearch Service によるベクトル検索とハイブリッド検索 - ハンズオンシナリオ

## シナリオ概要

あなたは IT コンサルティング会社のシニアエンジニアです。社内ナレッジベース（技術文書、トラブルシューティングガイド、プロジェクト報告書）を対象に、Amazon OpenSearch Serverless を使用したベクトル検索基盤を構築します。キーワード検索だけでは拾えない「意味的に近い文書」を発見し、さらにハイブリッド検索やカスタムスコアリングで検索精度を最適化する仕組みを実装します。

要件：
- Amazon OpenSearch Serverless（ベクトル検索コレクション）の構築
- k-NN ベクトル検索によるセマンティック検索の実装
- キーワード検索 + セマンティック検索を組み合わせたハイブリッド検索
- カスタムスコアリング関数による検索結果のランキング最適化
- インデックス設計（マッピング、k-NN アルゴリズム選択）

## 学習目標

このハンズオンを完了すると、以下ができるようになります：

1. **OpenSearch Serverless の構築**: ベクトル検索用コレクションのセットアップと IAM ポリシー設定
2. **ベクトル検索（k-NN）**: エンベディングを使った近似最近傍探索の実装と動作理解
3. **ハイブリッド検索**: セマンティック検索とキーワード検索（BM25）の統合による検索精度向上
4. **カスタムスコアリング**: script_score を使った独自スコアリング関数の設計
5. **インデックス設計**: マッピング定義、k-NN アルゴリズム（HNSW / IVF）の選択と最適化

## OpenSearch Service の主要機能（M03 テキスト対応）

| 機能 | 説明 | 本ハンズオンでの体験 |
|------|------|---------------------|
| k-NN ベクトル検索 | コサイン類似度による近似最近傍探索 | パート 2 |
| ハイブリッド検索 | BM25（キーワード）+ k-NN（セマンティック）の統合 | パート 3 |

## 使用する AWS サービス
