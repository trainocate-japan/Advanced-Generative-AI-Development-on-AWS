# モジュール 7: パフォーマンス最適化とコスト管理 - ハンズオンシナリオ

## シナリオ概要

あなたは EC サイト運営企業のプラットフォームエンジニアです。商品推薦 AI チャットボットの月間 API コストが急増しており、CFO から「品質を維持しながらコストを40%削減せよ」という指示を受けました。

プロンプトキャッシング、セマンティックキャッシュ、動的バッチ処理を組み合わせて、パフォーマンスを向上させながらコストを削減します。

## 学習目標

1. **トークン最適化**: コンテキスト圧縮とプロンプトキャッシングでトークンコストを削減する
2. **セマンティックキャッシュ**: ElastiCache + 埋め込みベクトルによる類似クエリキャッシュを実装する
3. **バッチ処理**: システム負荷に応じた動的バッチサイジングを実装する
4. **自動スケーリング**: AI ワークロードに最適なスケーリングポリシーを設計する

## 使用する AWS サービス

- Amazon Bedrock（Converse API + プロンプトキャッシング）
- Amazon ElastiCache（セマンティックキャッシュ）
- Amazon CloudFront（エッジキャッシュ）
- Amazon SQS（バッチキュー）
- Amazon CloudWatch（コストメトリクス）

## 所要時間

約 45 分
