# モジュール 3: ベクトルデータベースと検索拡張（RAG） - ハンズオンシナリオ

## シナリオ概要

あなたは大手法律事務所のテクニカルリードです。数万件の法律文書（判例、契約書テンプレート、規制ガイドライン）を管理するナレッジベースシステムを構築し、弁護士が自然言語で質問すると関連文書を検索・要約して回答する「リーガルアシスタント」を実装します。

要件：
- Amazon Bedrock ナレッジベースによる RAG 実装
- 法律文書に適したチャンキング戦略の選定
- セマンティック検索とキーワード検索を組み合わせたハイブリッド検索
- アクセス制御付きの会話型ナレッジアシスタント

## 学習目標

このハンズオンを完了すると、以下ができるようになります：

1. **ベクトルDB設計**: Amazon Bedrock ナレッジベースのセットアップと最適化
2. **チャンキング戦略**: ドキュメントタイプに応じた適応型チャンキングの実装
3. **ハイブリッド検索**: セマンティック検索 + キーワード検索の統合
4. **会話型アシスタント**: コンテキスト管理付きのナレッジアシスタント構築

│  Documents   │────▶│ Chunking Pipeline │────▶│  Vector Store    │

                                                         │

│   Query      │     │ Assistant         │

                             │
                      ┌──────▼───────┐
                      │   Bedrock    │

## 使用する AWS サービス

- Amazon Bedrock ナレッジベース（RetrieveAndGenerate API / Retrieve API）
- Amazon S3（ドキュメントストレージ）
- Amazon OpenSearch Serverless（ベクトルストア）※オプション
- Amazon Bedrock（埋め込みモデル: Titan Embeddings V2）
- Amazon Bedrock（生成モデル: Amazon Nova Pro）
