# モジュール 9: テスト、検証、継続的な改善 - ハンズオンシナリオ

## シナリオ概要

あなたは保険会社の AI 品質保証リードです。顧客向け保険相談 AI の品質を継続的に評価・改善するフレームワークを構築します。従来のソフトウェアテストとは異なるAI固有の課題（確率的出力、創発的動作）に対応した評価パイプラインを実装します。

## 学習目標

1. **評価フレームワーク**: 多次元の AI 品質評価メトリクスを設計する
2. **RAG 評価**: RAGAS フレームワークによる検索品質の評価
3. **A/B テスト**: プロンプトバリアントの効果測定
4. **継続的改善**: フィードバックループによる自動最適化パイプライン

## 使用する AWS サービス

- Amazon Bedrock（モデル評価ジョブ）
- Amazon CloudWatch（メトリクス）
- AWS Step Functions（評価パイプライン）

## 所要時間

約 45 分
