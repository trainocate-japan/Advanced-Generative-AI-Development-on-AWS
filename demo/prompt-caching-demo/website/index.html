Three-way comparison: Baseline (no cache) → Cache Write → Cache Hit (reading from cache)

📊 How This Demo Works

Each query makes three API calls to demonstrate caching: (1) Baseline without cache, (2) Cache Write to populate the cache, and (3) Cache Hit reading from the just-written cache. This shows the comparison in a single request. In real usage, you'd see cache hits on subsequent queries with the same document (within the 5-minute TTL).
